# Silicon interface build

Inspect revision/UI, DESIGN.md, content/components, accepted changes and supplied arrangement/capacity/growth. Separate requirements from speculation; preserve scope/brand. Local fixes need one direction.

## Compose the work

Before composing, find and visually inspect comparable category/task UI; prefer first-party. A page without that screen does not count: replace it or disclose the gap before using product evidence. Distinguish shipped/promotion/concept/unknown provenance. Reuse inspected material for local fixes; transfer grouping/density/action relationships, not skins/capabilities.

Name the dominant object, statement, action and critical values. Choose grid/rows from count/growth, recognition/comparison/sorting. Budget space after chrome/status; fit bounded sets intended together without scrolling at base size. Sketch against the existing reading model before replacing it. Narrow/enlarged text may scroll; tiny text, clipped/hidden content or needless pagination do not establish fit.

Across screens share roles, type/numbers, icons, density, chrome and component/state implementations; explain exceptions. Local fixes need no kit/framework.

Keep widths bounded, quantities/costs/units balanced and actions beside objects. Subtract labels/badges/help already conveyed by values, structure or selection. Prefer one enclosing boundary per object; justify nested frames and per-row card chrome. Align corner actions with headers. Preserve useful summaries, legends, instructions, empty/error/blocked reasons, programmatic names, context, targets and safeguards. Explain unfamiliar/consequential actions; report fixed-copy/DOM limits rather than fake controls.

On websites inspect headline breaks, navigation, comparable choices and destinations. Distinguish links, disclosures, selection and actions. Retain semantic status colour plus other cues; explain codes. Data needs visible units, near labels, source fidelity and distinct zero/unknown/not-applicable. Show exact action totals visibly at commitment; secondary precision may use reachable detail. Report contradictions; label fiction/prototypes; invent no testimonials, outcomes, assets or capabilities.

## Implement and inspect

Complete static frames; interactive work preserves input through affected blocked/failure/recovery. Add flows/surfaces/persistence checks only when needed/promised. Distinguish global/selected-object work, stopping/stopped and stale readiness; retain discoverable asynchronous outcomes after idle.

Exercise labels/icons/padding activation and keyboard paths. Check unexpected movement, clipping/overlays, sticky intersections and connected visible focus/context after close/removal/last-item undo. Deliberate reflow, reachable truncation detail and variable heights may be valid; stubs/hit-tests do not prove activation/focus.

Extend/remap colours coherently. Trace text/icon SVG/mask/filter inheritance, surfaces and crops; unreadable glyphs fail despite passing swatches.

Check capacity, minimum width/long translations, themes, growth/live values, actual zoom and reduced motion; recheck consumers. Before delivery compare same-state original/result for noise, hierarchy and action clarity; correct within budget and record removals/justified retentions. Report task-relevant shared defects outside edit scope. Separate technical coverage, unresolved craft and owner acceptance; source checks prove neither rendering/input nor compliance/audience effects.
