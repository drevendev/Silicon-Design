# Roadmap

## Initial foundation

The first version contains principles, typography/color/layout/interaction/accessibility foundations, separate website/app/game guidance, five portable skills, project/review templates, a source register and three fictional visual specimens. Static checks cover the declared repository contracts; the verification note records the narrower rendered checks.

## Next: apply it to a real product

First, use the [specimen critique](research/specimen-critique.md) as a revision brief rather than treating the initial gallery as a design benchmark. Its technical checks remain scoped evidence; its character needs more work. The expanded [principles](docs/principles.md) and [character guide](docs/character.md) address what the first pass missed.

1. Choose one representative flow from an existing product and capture its actual current implementation.
2. Record a project-specific DESIGN.md and compare meaningful directions if identity is changing.
3. Implement one selected direction without changing unrelated behavior.
4. Compare the same content, states and environments before and after; record keyboard, scaling, accessibility and task observations separately.
5. Keep the useful decisions and revise guidance only where evidence supports a broader lesson.

This application is future work. The fictional specimens are not its before/after evidence.

## Expand when usage justifies it

- Real agent trials for each skill, retaining inputs, output and observed failures.
- More theme and localization specimens, including long Cyrillic content.
- Native app and controller-runtime examples with actual device checks.
- A token interchange/export layer if multiple products need it.
- A plugin or installer if maintaining copied skill folders becomes a demonstrated problem.

No automatic redesigns, scheduled work, tool installation or cross-product migration is enabled by this repository.
