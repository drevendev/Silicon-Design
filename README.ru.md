# Silicon Design

Основы дизайна и скиллы для наших приложений, сайтов и игр.

Задача — научиться принимать и проверять дизайн-решения для конкретного продукта. У каждого проекта должны быть собственные характер, иерархия и визуальный язык; общими остаются качество, доступность и рабочий процесс.

Основной справочник ведётся на английском, как BeautifulRepo. Этот файл — короткий вход на русском.

## С чего начать

1. Прочитать [принципы](docs/principles.md) и [рабочий процесс](docs/workflow.md).
2. Заполнить [DESIGN.md](templates/DESIGN.md) в репозитории продукта: аудитория, задача, направление, типографика, цвет, композиция, состояния и критерии проверки.
3. Выбрать рекомендации для [сайта](docs/products/websites.md), [приложения](docs/products/apps.md) или [игры](docs/products/games.md).
4. Собрать один характерный сценарий на реалистичном контенте и проверить его по [чеклисту](checklists/design-review.md).
