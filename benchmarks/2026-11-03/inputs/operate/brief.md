# Operate — Dispatch

A repair-workshop operator finishes handovers for three fictional jobs. Preserve all fixture facts.

Start on lamp 017. Releasing with no address or original 18 must show a useful error without clearing a job. Corrected 18a clears only the lamp, updates open/handover counts and shows a receipt with the actual address. Undo restores the previous stage and chosen correction. Turntable 018 has a distinct collection action/note/drawing. Radio 019 cannot be released; state the missing switch/final test, with no checked/complete indication.

Secondary surface: handovers, truly empty until jobs clear, then derived from completed records. Open a completed record to inspect/undo. After both ready jobs clear, say radio remains waiting. Switching jobs, directions and handover/bench retains local context. Reset/reload restores all fixtures.

Required test adapters: job-17/18/19; address-original, address-corrected; release, collect, undo, reset; open-handovers, close-handovers; open-count, handover-count, operation-error; record-17/18 for completed records. No shipping/printing/service claim.

Fixtures: initial = fresh lamp; secondary = empty handovers; error = original-address error shown on unchanged lamp; complete = lamp delivered to 18a and turntable collected, handovers populated, radio still waiting.
